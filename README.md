## Proyectos destacados

### AutoReclamo — Plataforma web para gestión y seguimiento de reclamos

Plataforma web orientada a digitalizar, centralizar y mejorar la gestión de reclamos por siniestros. Permite cargar datos, validar información, administrar clientes y reclamos, consultar estados y mantener trazabilidad sobre cada etapa del proceso.

**Responsabilidades y aportes principales**

- Relevamiento de requerimientos con el cliente y definición del flujo operativo por estados.
- Desarrollo end-to-end de funcionalidades para carga, validación, administración y seguimiento de reclamos.
- Construcción de APIs REST con Node.js y Express para operaciones CRUD.
- Implementación de validaciones, manejo de errores y control de consistencia de datos.
- Modelado relacional en MySQL para persistencia, trazabilidad y consulta eficiente de información.
- Pruebas de endpoints con Postman y versionado del código con Git/GitHub.

**Stack:** JavaScript · Node.js · Express · MySQL · APIs REST · HTML · CSS · Git · Postman

**Demo:** https://autoreclamo-frontend.vercel.app/  
**Repositorio:** https://github.com/CharlesMatiasOl/Proyecto-tesis-AutoReclamo-Local

### Sistema de Reservas — Complejo de cabañas

Aplicación full stack para gestión de cabañas, disponibilidad, bloqueos de mantenimiento y administración interna. El sistema permite consultar disponibilidad por fechas, visualizar unidades disponibles y gestionar información desde un panel administrativo.

**Responsabilidades y aportes principales**

- Desarrollo de frontend con Next.js, React, TypeScript y Tailwind CSS.
- Construcción de backend con Node.js, Express y API REST.
- Implementación de lógica de disponibilidad por fechas y bloqueos de mantenimiento.
- Desarrollo de panel administrativo con autenticación JWT.
- Modelado de base de datos en MySQL.
- Separación entre frontend y backend para facilitar mantenimiento y escalabilidad.

**Stack:** Next.js · React · TypeScript · Tailwind CSS · Node.js · Express · MySQL · JWT · APIs REST

**Repositorio:** https://github.com/CharlesMatiasOl/cabanascordoba

### Sistema de Gestión de Mascotas — Aplicación Java

Sistema desarrollado en Java para gestionar información relacionada con mascotas, clientes y operaciones internas. Proyecto orientado a aplicar lógica de programación, arquitectura en capas, persistencia de datos y organización de código mantenible.

**Responsabilidades y aportes principales**
