## Proyectos destacados

### AutoReclamo — Gestión de Reclamos por Siniestros Automovilísticos

Plataforma web Full Stack desarrollada para digitalizar, centralizar y optimizar la gestión de reclamos por siniestros automovilísticos.

El sistema integra formularios para presentar reclamos, seguimiento por estados, gestión de clientes y un panel administrativo con herramientas de consulta, control y reportes.

**Principales funcionalidades y contribuciones:**

- Presentación de reclamos mediante formularios multipaso.
- Seguimiento por código y estados del proceso.
- Panel administrativo para gestión de clientes y reclamos.
- Implementación de APIs REST y reglas de negocio.
- Validación y persistencia de información mediante MySQL.
- Automatización de procesos administrativos.

**Impacto:** Reducción aproximada del 80 % en tareas manuales vinculadas a la gestión y seguimiento de información.

**Stack:** JavaScript · Node.js · Express · MySQL · APIs REST · HTML · CSS · Git · Postman

🔗 [Ver demostración](https://autoreclamo-frontend.vercel.app/) | [Repositorio GitHub](https://github.com/CharlesMatiasOl/Proyecto-tesis-AutoReclamo-Local)

### Cabañas Córdoba — Plataforma Full Stack de Reservas

Aplicación web desarrollada para gestionar alojamientos turísticos, consultar disponibilidad y administrar cabañas, reservas y bloqueos de mantenimiento.

**Principales funcionalidades y contribuciones:**

- Interfaz web desarrollada con Next.js, React y TypeScript.
- Búsqueda de alojamientos con filtros y selección de fechas.
- Cálculo de estadías según cantidad de noches y tarifas.
- Desarrollo de backend con Node.js, Express y APIs REST.
- Autenticación administrativa mediante JWT.
- Panel administrativo con operaciones CRUD.
- Gestión de disponibilidad y bloqueos de mantenimiento.
- Persistencia relacional mediante MySQL.

**Stack:** Next.js · React · TypeScript · Tailwind CSS · Node.js · Express · MySQL · JWT · APIs REST
